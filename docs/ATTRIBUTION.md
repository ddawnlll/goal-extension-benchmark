## Fixtures

`evaluation/fixtures/baseline-svgs/` are charts generated by the *pristine*
`bench/report.py` of Pi-Bolt over Pi-Bolt's own published benchmark results
(`bench/results/2026-10-10-pi-bolt-0.7.3`, MIT). They exist so the acceptance
suite can prove that ordinary input still produces byte-identical output.

The adversarial and acceptance tests were written for this benchmark.

## Text

The shared task in `results/shared-task.md` is the benchmark's task statement,
reproduced verbatim so that both runs can be checked against the same bytes
(and hash) that were submitted to the agents.
